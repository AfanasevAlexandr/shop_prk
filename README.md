# Telegram Mini App — каталог магазина

Статический фронтенд без сборщиков — размещается на GitHub Pages как есть.

## Структура

```
index.html          главная страница
css/styles.css       все стили, адаптация под тему Telegram
js/config.js          URL-адреса Apps Script и Make — ЗАПОЛНИТЬ
js/i18n.js             определение языка и подстановка переводов
js/api.js               загрузка каталога + отправка заказа
js/cart.js               состояние корзины (localStorage)
js/catalog.js            дерево категорий, фильтрация, рендер карточек
js/app.js                 точка входа, склеивает всё вместе
i18n/ru.json, en.json      строки интерфейса
assets/placeholder.svg      заглушка фото
```

## Что нужно сделать перед запуском

1. В `js/config.js` вставить:
   - `CATALOG_API_URL` — URL Web App из Apps Script (`Code.gs`), заканчивается на `/exec`.
   - `ORDER_WEBHOOK_URL` — оставить пустым до настройки Make. Пока пусто,
     отправка заказа работает в тестовом режиме (заказ выводится в консоль
     браузера вместо реальной отправки) — это позволяет протестировать
     весь интерфейс уже сейчас.

2. Залить содержимое папки в корень репозитория на GitHub → включить
   GitHub Pages (Settings → Pages → Source: main / root).

3. В BotFather у вашего бота:
   - `/newapp` или `/setmenubutton` → указать URL вида
     `https://ВАШ_ЛОГИН.github.io/ВАШ_РЕПОЗИТОРИЙ/`

## Проверка вне Telegram

Приложение открывается и в обычном браузере (для отладки вёрстки),
но `Telegram.WebApp` в этом случае недоступен — тема, MainButton и
данные пользователя работать не будут. Полноценно тестировать нужно
через сам Telegram (например, открыв тестовую ссылку в мобильном
клиенте или через @BotFather тестовый режим).

## Как формируется заказ

При нажатии "Подтвердить заказ" собирается объект вида:

```json
{
  "items": [{ "sku": "...", "name": "...", "qty": 2, "price": 899, "sum": 1798 }],
  "total": 1798,
  "currency": "р.",
  "customer": { "name": "...", "phone": "...", "comment": "..." },
  "telegram_user": { "id": 123, "username": "...", "first_name": "...", "language_code": "ru" },
  "telegram_init_data": "raw init data string",
  "created_at": "2026-08-23T12:00:00.000Z"
}
```

Этот объект и есть то, что уйдёт в вебхук Make на следующем шаге —
структуру можно уточнить перед подключением Make, если понадобится
что-то добавить или убрать.
